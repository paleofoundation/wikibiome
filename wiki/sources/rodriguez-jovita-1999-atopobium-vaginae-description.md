# Rodriguez Jovita 1999 — Atopobium vaginae description

## Study Scope

Rodriguez Jovita and colleagues characterized an organism isolated from the human vagina using phenotypic tests, whole-cell protein analysis, and 16S rRNA phylogeny. They proposed *Atopobium vaginae* for the species and designated CCUG 38953 as the type strain.

## Current Name

The species is now classified as [[fannyhessea-vaginae]]. The original name remains the basionym and is retained in this source record because it is the name used in the paper.
