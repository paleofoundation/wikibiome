# NCBI Taxonomy — Eubacteriales

## Record Scope

NCBI Taxonomy record 186802 uses *Eubacteriales* for the current order name and retains *Clostridiales* among the other names associated with the same taxon identifier.

## Editorial Use

This record supplies the stable NCBITaxon identifier and current database identity. Because NCBI Taxonomy is not itself a nomenclatural authority, WikiBiome also cites LPSN, the original 1917 publication, and the 1980 Approved Lists.
