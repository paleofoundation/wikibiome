# Index Fungorum — Candidozyma auris

## Record Scope

Index Fungorum lists *Candidozyma auris* (Satoh & Makimura) Q.M. Wang, Yurkov, Boekhout & F.Y. Bai 2024 as the current name, with registration identifier 848169. It records *Candida auris* Satoh & Makimura 2009 as the basionym and places the current combination in Metschnikowiaceae.

## Editorial Use

This nomenclatural record supports the accepted combination, authority, registration identifier, and basionym relationship. It does not support treating the historical combination as a separate species.
