# LPSN — *Lachnospira eligens*

## Record Scope

LPSN lists *Lachnospira eligens* (Holdeman and Moore 1974) García-López et al. 2020 as the correct, validly published name and *Eubacterium eligens* as a homotypic synonym. Both combinations share type strain ATCC 27750 = DSM 3376 = VPI C15-48.

## Editorial Use

This record supports WikiBiome's current canonical name, the historical-name relationship, and the type-strain continuity. It does not establish that every study using an “*Eubacterium eligens* group” label achieved species-level resolution.
