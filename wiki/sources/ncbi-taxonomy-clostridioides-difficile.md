# NCBI Taxonomy — Clostridioides difficile

## Record Scope

NCBI Taxonomy record 1496 uses *Clostridioides difficile* as the current name. It records *Clostridium difficile* as a validly published homotypic synonym and identifies the same type strains under that synonym.

## Editorial Use

This record supplies the stable NCBITaxon identifier and current database identity. NCBI states that its taxonomy database is not itself a nomenclatural authority, so WikiBiome also cites LPSN and the primary 2016 reclassification.
